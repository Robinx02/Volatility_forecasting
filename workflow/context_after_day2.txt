  sq_return       ← (log_return_{t-1})^2
  vix_level       ← VIX_{t-1}

  dxy_level       ← DXY_{t-1}

  us10y           ← US 10Y yield_{t-1}
  us10y_chg       ← US 10Y_{t-1} - US 10Y_{t-2}
  rate_spread     ← (india10y - us10y)_{t-1}
  callmoney       ← weighted avg call money rate_{t-1}
  nifty_ret       ← log(Nifty_{t-1}/Nifty_{t-2})
  em_ret          ← log(EEM_{t-1}/EEM_{t-2})
  ret_t           ← log return at t (GARCH input only, NOT an ML feature)
  is_mpc_day      ← 1 if today is RBI MPC announcement day (known in advance)
  is_fomc_day     ← 1 if today is FOMC statement day shifted to next Indian trading day
  day_of_week     ← 0–4
  month           ← 1–12
  week_of_year    ← 1–53

  rv range        : 0.004 – 0.281
  callmoney range : 0.13 – 54.32 (real historical spikes, not errors)
  75th pct RV     : 0.070  ← high-vol regime threshold
  is_mpc_day sum  : 60
  is_fomc_day sum : 175

                (4) 5-day-ahead horizon
